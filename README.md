# Sistema de Gestión de Reparaciones

## Descripción del proyecto

Este repositorio contiene la documentación técnica del Trabajo Práctico Integrador (TPI), correspondiente al desarrollo de un sistema de gestión de reparaciones en Python.

El proyecto busca facilitar el registro, la organización y el seguimiento de los trabajos de reparación, integrando los contenidos desarrollados durante las distintas etapas del trabajo.

## Alcance del sistema

El sistema está orientado a la gestión de reparaciones y al seguimiento de los trabajos registrados. Su desarrollo contempla funcionalidades para organizar la información de las reparaciones y facilitar su consulta.

Asimismo, se incorporó la posibilidad de generar un documento PDF con los datos de una reparación, permitiendo disponer de un registro organizado para su consulta o para compartirlo con el cliente.

El proyecto busca ofrecer una herramienta sencilla que contribuya a mejorar la organización de las tareas y la disponibilidad de la información.

## Organización del repositorio

La documentación se organiza en un único documento PDF que reúne las Entregas 1, 2 y 3, junto con el nuevo contenido correspondiente a la Entrega 4.

Se tomó la decisión de centralizar todo el material en un único archivo para evitar la duplicación de documentos, mantener la información organizada y facilitar su consulta.

La estructura del repositorio es la siguiente:

```text
sistema-gestion-reparaciones/
├── README.md
└── docs/
    └── Emanuel_Marin_TPI_entrega_4.pdf
```

### Descripción de los archivos

- **`README.md`:** presenta el proyecto, sus objetivos y la organización de la documentación.
- **`docs/Emanuel_Marin_TPI_entrega_4.pdf`:** contiene la documentación consolidada de las cuatro entregas del trabajo integrador.
